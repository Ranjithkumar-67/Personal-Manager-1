# 🚀 Personal Manage Pro

**Premium iOS Life Management Application** with Apple Liquid Glass UI

---

## ✨ Features

- 💰 **Money Management**: Expense tracking, budgets, analytics, Excel export
- ✅ **Tasks**: Apple Reminders-inspired with priorities and categories
- 📝 **Notes**: Clean note-taking with rich text and folders
- 🎯 **Goals**: Track short/long-term goals with progress visualization
- 📊 **Habits**: Daily tracking with calendar heatmap and streaks
- 🔒 **Security**: Face ID, local encryption, 100% offline

---

## 🎨 Design

**Apple Liquid Glass UI** with:
- Glassmorphism blur effects
- Smooth 60fps animations  
- Neon accents (Blue #0A84FF, Purple, Pink, Teal)
- Dark mode optimized
- Premium gradients and shadows

---

## 🛠 Tech Stack

- React Native 0.83 + TypeScript
- Zustand state management
- MMKV encrypted storage
- React Navigation v7
- Reanimated + Gesture Handler
- Linear Gradient + Blur

---

## 📦 Installation

```bash
npm install
cd ios && pod install && cd ..
npm run ios
```

---

## 🔒 100% Offline & Private

All data stays on YOUR iPhone. No cloud, no tracking, complete privacy.
